# Weight Plate Web

Macro and weight plate tracking web application with Playwright E2E tests.

## What this project does

- Tracks food intake, serving sizes, and macro nutrients
- Provides an admin edit flow for managing food data and servings
- Validates nutrition calculations and prevents invalid inputs
- Includes a full Playwright test suite covering serving UI, validation, defaults, deletion, and API failure handling

## Tech Stack

- TypeScript
- Playwright
- HTML/CSS
- Node.js

## How to Run

```bash
npm install
npx playwright install
npm test
npm run report
```
