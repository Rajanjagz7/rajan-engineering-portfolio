# Learn Playwright

## About
Playwright learning scripts and examples progressing from first script through locators, forms, interactive controls, and pytest integration.

## Tech Stack
- Python
- Playwright for Python
- Pytest

## How to Run
```bash
python -m venv .venv
.venv\Scripts\activate
pip install playwright pytest
playwright install
python 01_first_script.py
pytest test_04_pytest_playwright.py
```
