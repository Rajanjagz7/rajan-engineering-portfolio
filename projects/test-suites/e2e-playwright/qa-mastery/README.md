# QA Mastery

## About
QA mastery learning projects spanning Playwright TypeScript test automation and AI evaluation patterns with Python.

## Tech Stack
- TypeScript
- Playwright
- Python

## How to Run
```bash
# Playwright TypeScript
cd 01-playwright-ts
npm install
npx playwright test

# AI Evals Python
cd 02-ai-evals-py
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
pytest
```
