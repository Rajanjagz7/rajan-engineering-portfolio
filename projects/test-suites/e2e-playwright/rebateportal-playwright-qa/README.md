# RebatePortal Playwright QA

## About
Full Playwright QA suite for RebatePortal. Covers API, authentication, modules, session management, cross-browser testing, and TypeScript type checking.

## Tech Stack
- TypeScript
- Playwright
- Node.js

## How to Run
```bash
cd rebateportal-playwright
npm install
npx playwright install
npm test
npm run test:api
npm run test:auth
npm run test:modules
npm run test:cross-browser
npm run report
```
