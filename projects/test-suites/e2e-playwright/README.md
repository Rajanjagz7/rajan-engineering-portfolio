# E2E Playwright

## About
End-to-end Playwright test suites covering web apps, mobile, cross-browser, and advanced framework patterns.

## Sub-Projects
- `playwright-tests/` - Cross-browser e-commerce tests with Capacitor mobile support
- `saucedemo-advanced-e2e/` - 8-layer Sauce Demo + FakeStoreAPI framework
- `saucedemo-e2e-tests/` - Sauce Demo e-commerce tests
- `shopify-mobile-tests/` - Shopify mobile navigation and cart tests
- `rebateportal-tests/` - RebatePortal NSW project creation tests
- `rebateportal-playwright-qa/` - Full RebatePortal QA suite (API, auth, modules, session)
- `energy-rebate-tests/` - er project management tests
- `energy-rebate-tests-pure-puppeteer/` - Raw Puppeteer scripts for RebatePortal NSW
- `qa-mastery/` - Playwright TypeScript and AI evals learning projects

## Tech Stack
- TypeScript
- Playwright
- Puppeteer
- Docker (select projects)
