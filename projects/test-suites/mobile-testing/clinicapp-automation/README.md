# ClinicApp Automation

## About
Comprehensive ClinicApp automation suite covering appointments, billing, telehealth, patient creation, and practitioner workflows using Playwright, Selenium, and Pytest.

## Tech Stack
- Python
- Playwright for Python
- Selenium
- Pytest

## How to Run
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
playwright install
pytest
```
