# ClinicApp Tests

## About
Playwright mobile test scripts for ClinicApp covering billing, appointment creation, and telehealth workflows.

## Tech Stack
- Python
- Playwright for Python

## How to Run
```bash
python -m venv .venv
.venv\Scripts\activate
pip install playwright
playwright install
python clinicapp_billing_playwright.py
python clinicapp_create_appointments.py
python clinicapp_telehealth_elly.py
```
